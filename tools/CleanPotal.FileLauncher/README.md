# CleanPotal 원본 파일 실행 도우미

웹 브라우저가 직접 열 수 없는 사내 UNC 공유 파일을 사용자의 Windows 연결 프로그램으로 엽니다.
파일 경로나 실행 명령은 웹에서 직접 받지 않고, API가 발급한 20초짜리 1회용 실행권만 받습니다.

## 보안 경계

- 사용자 로그인과 `ViewOffice` 권한이 있어야 실행권을 발급할 수 있습니다.
- 실행권에는 경로가 없고, 무작위 256비트 값이며, 한 번 사용하거나 20초가 지나면 폐기됩니다.
- API와 도우미가 각각 허용 UNC 루트를 검사합니다.
- 도우미는 문서 확장자만 허용하고 실행 파일, 스크립트, 바로가기와 매크로 문서는 거부합니다.
- 실제 파일을 열기 전에 파일명과 폴더를 보여 주고 사용자 확인을 받습니다.
- 로컬 시험에서만 `http://localhost`를 허용합니다. 다른 PC에 배포할 때는 신뢰된 인증서가 적용된 HTTPS API 주소만 허용됩니다.

동일 Windows 사용자 권한으로 실행되므로 공유 파일 접근 및 저장 권한은 그 사용자의 파일서버 권한을 따릅니다.
도우미가 파일서버 권한을 우회하거나 관리자 권한을 얻지는 않습니다.

## 운영 배포 전 필수 사항

1. 포털과 API를 HTTPS로 배포합니다.
2. 회사 인증서로 실행 파일과 설치 패키지에 코드 서명합니다.
3. 회사 소프트웨어 배포 도구로 배포하고 파일 해시 또는 서명을 검증합니다.
4. 중앙 로그에 사용자, 항목 ID, 실행권 발급 및 사용 결과를 남깁니다.
5. API를 여러 대 운영하면 메모리 저장소 대신 Redis 또는 DB 기반 1회용 저장소를 사용합니다.

## 제거

`uninstall.ps1`은 현재 사용자에게 등록된 `cleanpotal://` 프로토콜과
`%LOCALAPPDATA%\CleanPotal\FileLauncher`만 제거합니다.

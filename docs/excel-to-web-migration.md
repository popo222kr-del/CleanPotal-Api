# Excel 업무의 웹 전환 계획

작성일: 2026-09-17

## 조사 결과

- 업무 파일 통합 관리에 등록된 Excel 통합문서는 26개다.
- 26개 모두 파일서버에서 접근할 수 있다.
- 26개 모두 일반 XLSX/ZIP 파일이 아니라 `SCDSA004` 헤더의 사내 DRM 문서다.
- 서버의 일반 Excel 라이브러리로는 내용을 읽을 수 없다. 권한이 있는 Windows PC의 Microsoft Excel을
  매크로 및 외부 링크 비활성화, 읽기 전용으로 실행하면 구조를 읽을 수 있다.
- 일부 통합문서는 사용 영역이 전체 행(1,048,576행) 또는 전체 열(16,384열)로 오염되어 있다.
  `UsedRange` 전체를 그대로 데이터로 이관하면 안 되고 실제 표 범위를 업무 규칙으로 판별해야 한다.

## 전환 원칙

Excel 모양을 브라우저 표로 그대로 복제하지 않는다. 업무 개념을 DB 테이블과 검증 규칙으로 옮긴다.

1. 입력 데이터는 정규화된 업무 테이블에 저장한다.
2. 계산식은 서버 업무 규칙 또는 검증 가능한 조회식으로 옮긴다.
3. 사용자, 수정일시, 변경 전후 값과 삭제 사유를 감사 이력으로 남긴다.
4. 여러 사용자가 동시에 수정할 때 버전 충돌을 검출한다.
5. 조회, 등록, 수정, 승인, 삭제 권한을 분리한다.
6. Excel은 전환 완료 후 읽기 전용 보관 자료로만 유지한다.
7. 과거 데이터 이관은 DRM을 해제한 사본을 만들지 않고, 승인된 PC에서 Excel을 읽어 정규화된 값만 API로 전송한다.

## 구현 순서

### 1단계: 이미 웹 화면이 있는 업무

- 금강·영신·우암·세메스 전산등록과 입출고
- 생산팀 근무표
- Metal/N-Metal ICP-MS
- Bake, Laser 공정
- 폐기품·불량

기존 화면의 누락 필드를 보완하고 Excel 기준정보와 과거 데이터를 이관한다. 이 단계가 끝난 항목부터
업무 파일 화면의 Excel 링크를 해당 웹 화면으로 바꾼다.

### 2단계: DOME 업무

DOME 현황, 외주 입고, 작업일보, RunSheet를 하나의 DOME 모듈로 만든다. 동일 제품과 LOT을 네 파일에서
중복 관리하지 않고 하나의 기준정보와 이력으로 연결한다.

### 3단계: Chemical·설비 업무

폐액량, 약액교체, Bath 용량, Chemical 사용, 폐수 점검, 설비 변경점을 하나의 Chemical 모듈로 만든다.
월별 시트를 새로 만드는 대신 날짜·설비·약액 기준으로 계속 누적하고 월별 조회를 제공한다.

### 4단계: 품질·보고 업무

SEMES 분석, SPC/MUS, 눈관리, CC, 청소, 데일리메일, 담당자 주소록을 각각의 업무 데이터로 전환한다.

### 5단계: 종료 검증

- Excel 행 수와 웹 이관 건수를 업무 키 기준으로 대조한다.
- 금액, 수량, 최근 상태와 월별 합계를 표본 검증한다.
- 담당자가 웹에서 신규 등록·수정·조회·내보내기를 승인한 뒤 Excel을 읽기 전용 보관으로 전환한다.

## 첫 대상: 금강쿼츠 B급

`전산 등록` 시트의 9개 열은 현재 MES 전산등록 화면과 일치한다.

| Excel | 웹 MES |
|---|---|
| 반출일 | 고객출고일 |
| 반출번호 | 반출번호 |
| S/N | S/N |
| 세정코드 | 세정코드 |
| 라인 | LINE |
| Process | PROCESS |
| 설비명 | 업체명/설비명 |
| 분임조(담당자) | 분임조 |
| 수량 | 수량 |

`기준 정보` 시트에는 금강쿼츠 업체코드 `11009`와 B급 제품 8개, 세정코드
`700031189`~`700031196`, 단가가 있다. 현재 MES DB에는 이 업체와 제품 8개가 등록되어 있지 않다.
전산등록 화면 자체는 준비됐지만 기준정보가 없어서 지금 상태로는 등록할 수 없다.

첫 이관 전에 다음 값을 확정해야 한다.

- 금강쿼츠 반출번호 접두어
- B급 제품 8개의 품목코드와 제품 규격
- 적용할 공정 플로우
- 단가 적용 시작일
- 기존 7개 전산등록 행을 과거 이력으로 넣을지, 기준정보만 넣을지

이 값이 확정되면 제품·단가·기본 LINE·공정 플로우를 등록하고, 업무 파일의 금강쿼츠 B급 항목을
`/mes/register`로 전환한다.

## 운영 전 재검토 사항

- 현재 개발 서버는 HTTP다. 운영 배포 전 HTTPS가 필요하다.
- 이관 도구는 사용자 PC의 Excel/DRM 권한으로만 실행하고 서버에 설치하지 않는다.
- 여러 API 인스턴스를 운영할 경우 감사 이력과 중복 이관 방지 키를 중앙 DB에 둔다.
- 월별 Excel 시트 이름이나 셀 위치를 업무 키로 사용하지 않는다.

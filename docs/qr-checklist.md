# QR 체크시트 (3정 5S 점검) — 1단계

구역(방)마다 QR 을 붙이고, 현장 작업자가 **개인 휴대폰 카메라**로 찍어 점검한다. 사무실에서는 메뉴 `현장 점검 → 체크시트` 에서 현황·NG·월간 리포트를 본다.

## 1. 흐름

1. 휴대폰 기본 카메라로 구역 QR 을 찍는다 → `http://서버/c/M-OUT` 가 열린다(사내 와이파이 필요).
2. 로그인 안 돼 있으면 로그인 화면 → 로그인하면 그 구역 화면으로 돌아온다(로그인은 12시간 유지).
3. 화면에는 **오늘·지금 교대에 해당하는 항목만** 뜬다: 공통 항목(M-ALL) → 그 구역 항목 → 주 1회 → 필요할 때.
4. 항목마다 OK / NG(/N/A) 를 누르거나 수치를 넣는다. 누르는 즉시 저장된다.
   - 수치(정전기)는 서버가 기준(±500V)으로 합격/불합격을 판정한다.
   - NG 면 사유(필수)와, 사진 정책이 "NG 시" 면 NG 사진을 찍는다.
   - 주 1회 항목은 사진 정책대로 작업 전·후 사진을 찍는다(촬영 시각은 서버가 받은 시각으로 남는다).
5. "제출" — 빠진 필수 항목·사유·사진이 있으면 목록으로 알려 주고 막는다. 제출하면 마감.

## 2. 규칙

| 구분 | 내용 |
|---|---|
| 근무일·교대 | 주간 07:00, 야간 17:30 시작(설정에서 변경). 야간이 자정을 넘겨도 **시작일**로 기록 |
| 입력 가능 | 현장 점검 **조회(1)** 등급 이상 — 생산직은 조회만 주면 QR 점검·사진·제출을 한다(재고·ICP-MS 등 다른 현장 점검 메뉴는 보기만). NG 조치 완료는 편집(2), 양식 관리는 관리자. 관리자가 아니면 **지금 교대와 바로 앞 교대만** 입력·제출. 관리자는 지난 교대도 입력하지만 **시작 전 교대는 누구도 입력하지 못한다**(현황에 "시작 전") |
| 제출 후 수정 | **관리자만**, 수정 사유 필수. 전·후 값과 사유가 자료 변경 이력(ContentAudits, "체크시트")에 남는다 |
| 주 1회 | 지정 요일부터 해당, 지나면 "밀림". 그 주(월~일)에 한 번 하면 끝. 요일이 비어 있으면 그 주 아무 날 |
| 공통 항목 | M-ALL 같은 공통 구역의 항목은 같은 라인 모든 구역 화면에 뜨고 **구역마다 따로** 기록 |
| 구역코드 | 바꿀 수 있다 — 그 구역 항목·점검 기록이 새 코드로 따라간다. 다만 QR 주소가 바뀌므로 그 구역 라벨은 다시 인쇄한다. 이름·부착 위치는 바꿔도 QR 그대로. 기록이 없는 구역은 지울 수 있다 |
| 항목 개정 | 결과에 당시 문구·기준을 복사해 두므로, 항목을 고쳐도 과거 기록은 그대로. 기록이 있는 항목은 지우지 못하고 '사용' 을 끄거나 적용 종료일을 넣는다 |
| NG | 미조치 NG 목록에 남고, 편집 권한자가 조치 내용을 적어 "조치 완료" 처리(담당부서 조치 흐름은 시범 운영 뒤 2단계) |

| 사진 저장 | 휴대폰에서 1400px JPEG 로 줄여(한 장 약 0.2MB) 첨부 보관소(설정 시 NAS) `체크시트\yyyy-MM\날짜_시각_교대_구역_항목_구분.jpg` 로 둔다. DB 에는 위치만 한 줄(`docs/attachments-storage.md`). 첨부 올리기는 원래 편집(2) 등급이지만 현장 점검(field) 사진만 조회(1) 등급도 올린다. **DB 를 백업할 때 보관소 폴더도 같이** 백업한다 |

## 3. 사무실 화면

- **점검 현황**: 구역 × 주간/야간(미점검·진행 중·제출, 완료 수, NG), 주 1회 오늘/밀림. 칸을 누르면 그 구역 화면(QR 없이 들어온 것으로 기록).
- **미조치 NG**: 사진·사유·측정값, 조치 완료 처리.
- **월간 리포트**: 라인·월 선택 → 항목 × 일(위=주간, 아래=야간) 표. ○ 양호 / ✕ NG / 숫자 / N/A / **미**(점검 안 함). 구역별 이행률, NG 목록, 작성·검토·승인 칸. **인쇄(A3 가로)**, **엑셀 저장**.
  - "미" 는 설정의 **시행일**부터 표시한다(비어 있으면 이 체크시트를 처음 쓴 날부터).
- **양식 관리(관리자)**: 점검 항목, 구역(라인 복사 포함), QR 라벨 인쇄(A4 2열), 설정, 엑셀 가져오기.

## 4. 처음 배포할 때

1. 배포하면 새 표(`CheckZones`, `CheckItems`, `CheckRuns`, `CheckResults`, `CheckSettings`)가 자동으로 생기고, 비어 있으면 METAL 7구역·33항목(보내 준 양식 입력 파일)이 들어간다. 예전 `InspectionItems/Records` 표는 더 쓰지 않는다(DB 에 남아 있어도 무방).
2. 양식 관리 → **QR 라벨** 위쪽 "QR 주소" 를 서버 주소(`http://10.10.10.119:8713` 또는 사내 DNS 이름)로 저장한다. 서버에서 `localhost` 로 열어 둔 채 만들면 휴대폰이 열 수 없는 주소가 들어가므로, 그때는 경고가 뜨고 인쇄가 막힌다. **설정**에서 시행일·교대 시각도 확인.
3. 양식 관리 → **점검 항목**: 주 1회 항목 14개의 **요일**, NG 담당부서 입력. **구역**: QR 부착 위치 입력.
4. **N-METAL**: 양식 관리 → 구역 → **라인 복사**(METAL → N-METAL, 코드 앞글자 M → N)로 구역·항목을 통째로 복사한 뒤, 이름·부착 위치·항목을 N-METAL 에 맞게 고친다. 번호는 맞춰진다(M-012 → N-012). 점검 기록·QR 부착 위치는 복사하지 않는다. 엑셀 가져오기로 N- 구역·항목을 올려도 된다.
5. **QR 라벨** 인쇄 → 휴대폰으로 한 장 찍어 화면이 열리는지 확인 → 시범 구역(출고검사실)에 1주 부착.

## 5. 2단계로 미룬 것

- 설비 QR(`/e/설비코드`)과 설비 점검 항목(엑셀 4·5번 시트), 약액 교체 같은 이벤트 기록
- NG 담당부서 조치 흐름(요청 → 조치 → 재점검)
- 종이 양식(5S CHECK SHEET 등) 모양의 출력 — 1단계는 월간 리포트로 대신

세정 업무 통합 관리 사용 설명서

세정팀 업무 포털(웹)의 메뉴별 사용법입니다.
메뉴는 왼쪽 사이드바 순서대로 정리했고, 화면마다 들어가는 길·필요한 권한·주요 기능을 적었습니다.
왼쪽 위 검색창(폰에서는 맨 위)에 화면 이름이나 기능을 넣으면 해당 카드만 남습니다.

로그인과 화면 구성START

회사 PC·사내 와이파이에서 주소창에 포털 주소를 열고 사번(아이디)과 비밀번호로 로그인합니다.

로그인

  • 계정은 관리자가 사용자 계정 관리에서 만들어 줍니다.
    받은 비밀번호는 왼쪽 아래 톱니바퀴(계정 설정)에서 바로 바꾸세요.
  • 로그인한 상태는 브라우저에 남아 있어 다음에 바로 들어갑니다.
    공용 PC에서는 왼쪽 아래 Logout을 눌러 나갑니다.
  • 왼쪽 아래 톱니바퀴는 계정 설정(내 아이디·비밀번호 변경)입니다.

화면 구성

  • 왼쪽 사이드바 — MAIN(대시보드·MES), WORKSPACE(일정·보고·세정 작업·설비·자재·OFFICE), ADMIN(관리자) 순서입니다.
    권한이 없는 메뉴는 보이지 않습니다.
    위쪽 메뉴 검색으로 화면 이름을 찾아 바로 갈 수 있습니다.
  • 위쪽 탭 — 연 화면이 탭으로 쌓입니다(고정하지 않은 탭은 12개까지, 오래된 것부터 닫힘).
    📌 고정한 탭은 맨 앞에 붙고 내 계정에 저장되어 어느 PC에서든 같습니다.
    오른쪽 다른 탭 닫기로 정리합니다.
  • 서버 표시 — 사이드바 위 주황색 띠는 테스트 서버, 그 밖은 운영 서버입니다.
    띠 옆 숫자는 지금 올라가 있는 버전과 시각입니다.
  • 햄버거(≡)로 사이드바를 접고 펼칩니다.

공통 사용법COMMON

자주 쓰는 동작

  • 엑셀 — 표 화면 대부분에 엑셀(또는 엑셀 내보내기) 버튼이 있어 지금 보이는 조건 그대로 내려받습니다.
  • 새 창으로 보기 — LOT 목록·세정 이력·입고검사 이력 등은 사이드바 없이 넓은 새 창으로 띄워 나란히 비교할 수 있습니다.
  • 숫자 누르기 — 현황표의 숫자(건수·금액)를 누르면 그 숫자를 이루는 LOT·품목 목록이 열립니다.
  • LOT ID 누르기 — LOT 상세(성적서 모양의 LOT 카드, 공정 진행·이력, 검사 측정값)가 새 창으로 열립니다.
  • 휴대폰 — 화면 아래에 자주 쓰는 메뉴 칸(모바일 하단 메뉴)이 나옵니다.
    가운데 QR 스캔으로 체크시트 구역·설비 QR을 찍어 바로 들어갑니다.
화면이 예전과 같다면 — 새 버전이 올라간 뒤에도 브라우저가 예전 화면을 기억하고 있을 수 있습니다. Ctrl + Shift + R로 새로고침하세요.

휴대폰 홈 화면에 추가MOBILE

휴대폰 홈 화면에 아이콘으로 추가하면 주소창 없이 앱처럼 전체 화면으로 열립니다.
아이콘 이름은 세정통합웹입니다.
사내 와이파이에 연결한 상태에서 하세요.

아이폰 (사파리)

  • 사파리로 포털 주소를 열고 로그인합니다.
    크롬 등 다른 브라우저에서는 메뉴가 다를 수 있으니 사파리를 쓰세요.
  • 화면 아래(또는 위) 공유 버튼(네모에 위쪽 화살표)을 누릅니다.
  • 목록을 내려 홈 화면에 추가를 누르고, 이름(세정통합웹)을 확인한 뒤 오른쪽 위 추가.
  • 홈 화면의 세정통합웹 아이콘으로 엽니다.

안드로이드 (크롬 · 삼성 인터넷)

  • 크롬: 포털 주소를 열고 오른쪽 위 ⋮ → 홈 화면에 추가(또는 앱 설치) → 추가.
  • 삼성 인터넷: 아래 ≡ → 현재 페이지 추가 → 홈 화면.
  • 홈 화면의 세정통합웹 아이콘으로 엽니다.

홈 화면 앱으로 쓸 때

  • 화면 아래 하단 메뉴로 자주 쓰는 화면에 갑니다.
    가운데 QR 스캔으로 체크시트 구역·설비 QR을 찍으면 앱 안에서 바로 그 화면이 열립니다.
  • 휴대폰 기본 카메라로 QR을 찍으면 앱이 아니라 브라우저(사파리·크롬)로 열립니다.
    앱 안에서 쓰려면 앱의 QR 스캔을 쓰세요.
  • 새 버전이 올라가면 앱을 다시 열 때 자동으로 새로고침됩니다.
    쓰는 중이면 아래에 "새 버전" 안내가 나오니 눌러서 새로고침하세요.
  • 앱 아이콘과 브라우저는 로그인이 따로일 수 있습니다.
    앱에서 처음 열 때 한 번 로그인하세요.
화면이 이상하거나 상단이 겹치면 홈 화면 아이콘을 지우고 위 순서로 다시 추가하세요.

  • 화면 구성(오른쪽 위) — 카드를 켜고 끄고 순서를 바꿉니다.

OPER (공정)

/mes/oper/2000 ~ 8100MES 편집

공정마다 한 화면입니다: 입고(2000) · 입고검사(2100) · 세정(3000) · 건조(4000) · Laser&CO2(4100) · Bake(5000) · 출고검사(7000) · 포장완료(7100) · 고객출하(8100).

  • LOT을 스캔하거나 목록에서 골라 설비·레시피·작업자를 넣고 실행하면 다음 공정으로 넘어갑니다.
  • 검사 공정은 측정 항목(PARAMETER)과 MIN/MAX가 나오고, 값을 넣고 저장합니다.
  • 위쪽 MES 메뉴에서 LOT 스캔·전산등록·Batch·입출고 현황·세정 이력·HOLD·재작업·성적서·이력 삭제·TAT·셋업 화면을 창으로 엽니다.
셋업(업체·공정·단가/이미지 마스터)은 셋업 권한이 있는 계정만 바꿀 수 있습니다.

삼성 입·출고 현황 / 기타 입·출고 현황

삼성(MEMORY·FOUNDRY)과 기타세정(고객사별)이 따로 있습니다.

  • 탭: 재공 현황 · 세정 이력 조회(입고일 기간·조건으로 LOT 찾기) · LOT 현황 조회.
  • 숫자를 누르면 아래에 LOT 목록이 열립니다(LOT ID·반출번호·S/N·구분·세정코드·품명·제품군·입고일·현재 상태·라인·PM설비·분임조·공정·사용횟수·판정).
  • 판정 칸은 측정 합부판정 마지막 값: OK 파랑, NG 빨강, CC 주황.
    판정 전은 빈칸.
  • 새 창으로 보기, 엑셀로 목록을 따로 봅니다.

LOT 상세 (어디서든 LOT ID를 누르면)

  • 공정 진행·이력 — 단계별 요약(일시·설비·작업자·소요·레시피·기준 시간). 이력 펼치기로 전체 이력.
  • 검사 측정값 — 성적서 양식(Item·측정방법·SPEC·입고·출고·Remark).
    외관 Y·SPEC 밖은 빨강.

바뀌었다는데 화면이 예전 그대로예요

브라우저가 예전 화면을 기억하고 있는 경우입니다. Ctrl + Shift + R로 새로고침하세요.
휴대폰은 앱(브라우저)을 완전히 닫았다가 다시 엽니다.

출하실적 금액이 기존 MES와 달라요

출하실적 현황 표 아래 기존 MES 실적과 다른 이유를 보세요.
기존 MES 화면은 단가 이력이 없는 품목과 라인 코드표에 없는 라인의 LOT을 빼고 셉니다. MES 화면 예상 줄이 기존 MES 금액과 같아야 합니다.

QR을 찍었는데 안 열려요

사내 와이파이에 연결돼 있는지 확인하세요.
로그인이 풀려 있으면 로그인 후 그 구역 화면으로 돌아옵니다.
웹앱 안의 QR 스캔을 쓰면 브라우저가 아니라 웹앱 그대로 열립니다.
